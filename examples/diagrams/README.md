# Примеры диаграмм D2

Эти текстовые файлы D2 созданы по данным из `tests/data/repository.json`:

- `A.d2` — граф, достижимый из пакета A (пять вершин).
- `B.d2` — граф, достижимый из пакета B (три вершины и цикл).
- `C.d2` — граф, достижимый из пакета C (четыре вершины и цикл).

Изображения PNG создаются локально с помощью D2 и не добавляются в Git,
поскольку правила репозитория запрещают хранение бинарных файлов.
